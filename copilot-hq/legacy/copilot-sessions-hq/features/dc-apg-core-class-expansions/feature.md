## Goal

Add APG option packs for existing core classes, including Toxicologist alchemist, Superstition barbarian, Warrior muse bard, evil champions, Eldritch Trickster and Mastermind rogues, Genie and Nymph sorcerer bloodlines, and Staff Nexus wizard thesis.

## Source reference

> APG extends core classes with new research fields, instincts, muses, causes, rackets, bloodlines, and arcane theses, each with its own prerequisites and progression rules.

## Implementation hint

Extend the character-class option model so classes can register additional subclass choices, anathema or access restrictions, free feat grants, spell-list differences, key-ability substitutions, and spellbook or staff behaviors. Keep these as option bundles under the relevant existing class implementations rather than separate top-level classes.
